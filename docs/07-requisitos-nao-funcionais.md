# Requisitos não funcionais

| ID | Requisito |
|---|---|
| RNF01 | Plataforma web responsiva, acessível pelo navegador no celular e no computador, sem aplicativo para instalar. |
| RNF02 | Usabilidade: reservar em poucos passos, com linguagem simples, para usuários que usam o sistema de forma esporádica. |
| RNF03 | Identidade visual alinhada à da Mútua: tons de azul, amadeirado e branco gelo (evitar branco puro), seguindo o site e a sede da Mútua. A aplicação visual oficial está no [Framer](09-design.md). |
| RNF04 | Comunicação: WhatsApp como canal principal de contato; e-mail para registro formal (ex.: ocorrências). |
| RNF05 | Proteção de dados (LGPD): coletar só os dados necessários (nome, RNP, WhatsApp, e-mail), informar a finalidade e restringir o acesso à equipe da Mútua-PI. |
| RNF06 | Acessibilidade: boas práticas de acessibilidade web (contraste, navegação por teclado, textos alternativos). |
| RNF07 | Evolução: arquitetura preparada para integrar, no futuro, com o banco de dados da Mútua/Crea e para incluir cobrança. |
| RNF08 | Disponibilidade: reservas possíveis a qualquer hora, inclusive à noite e nos fins de semana, horários de maior uso do auditório. |
