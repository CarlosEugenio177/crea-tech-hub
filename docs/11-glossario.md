# Glossário

| Termo | Definição |
|---|---|
| Mútua | Caixa de Assistência dos Profissionais do Crea. Mutualista é o profissional associado a ela. |
| Crea | Conselho Regional de Engenharia e Agronomia. Quem é registrado no Crea contribui com a Mútua. |
| RNP | Registro Nacional do Profissional, número de identificação do profissional no sistema Confea/Crea. |
| ESE | Escola Superior de Engenharia, ligada à Mútua, que oferece inclusive pós-graduação. |
| Estação | Posto de trabalho ou estudo individual, reservado separadamente. |
