# CTH-22 - Proteção de dados pessoais (LGPD)

| Campo | Valor |
|---|---|
| **Prioridade** | Alta (MVP) |
| **Requisitos** | RNF05 |
| **Depende de** | — (transversal), CTH-12 |

## Objetivo

Tratar os dados dos solicitantes conforme a LGPD: coletar só o necessário, informar a finalidade e restringir o acesso à equipe da Mútua-PI.

## Quem usa

| Perfil | O que faz |
|---|---|
| Solicitantes (todos os perfis) | Informam seus dados com transparência sobre o uso |
| Equipe da Mútua-PI | Acessa os dados apenas para operar o Hub |

## Indicadores de sucesso (proposta da equipe)

- Nenhum dado pessoal exposto fora da equipe autorizada.

## História

**Como** solicitante, **quero** saber para que meus dados serão usados e ter certeza de que só a equipe da Mútua-PI os acessa, **para** reservar com confiança.

## Critérios de aceite

- [ ] São coletados **somente** nome, RNP (quando profissional), WhatsApp e e-mail, além do motivo quando exigido.
- [ ] O formulário informa a **finalidade** do uso dos dados.
- [ ] O acesso aos dados dos solicitantes é **restrito à equipe da Mútua-PI** (CTH-12).
- [ ] Telas e URLs públicas (comprovante, cancelamento) **não expõem** dados de outras pessoas.
